Omni-mode is unsupported. Get the same effect by assigning all osc to the same channel
MultiTimbral mode (poly off, default):
    each osc is assigned to a MIDI channel. each osc is monophonic, playing the most recent note received
Poly mode:
    each osc is assigned to a MIDI channel. within that channel, notes are polyphonic, switching between each assigned osc.
    if only one osc is assigned to the channel, it's effectively monophonic (mode 1)
