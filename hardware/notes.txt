TAC = 00, TMA=0xFF-16 will create a 256Hz interrupt


envelope state:
STATE_OFF, STATE_ATTACK, STATE_ON, STATE_RELEASE

attack: 3 bits (@ 64Hz timer per volume tick. For full volume, ~250ms to 1.7s)
- if sweep_pace is zero: go straight to STATE_ON with volume set. else:
- STATE_OFF -> STATE_ATTACK
- NRx2: initial volume = 0, env dir = up, sweep pace [3 bits]
- NRx4: len=disabled, trigger
- attack complete after sweep_pace*4*volume interrupt ticks (max 8*4*16=512. Or if use 64Hz timer, 128)

on:
- if hold mode, ignore timer. next state from NOTE_OFF. else:
- STATE_ATTACK -> STATE_ON
- NRx2: initial volume = <vol>, sweep pace = 0 (disabled)
- NRx1: len=<len>
- NRx4: len=enabled, trigger
- length=8bits for osc3, else 6 bits. ticks at 256Hz
- hold complete after len interrupt ticks (max 256)

release:
- same settings as attack, but reversed
- STATE_ON -> STATE_RELEASE
- NRx2: initial volume = <vol> env dir = down, sweep pace [3 bits]
- NRx4: len=disabled, trigger


portamento:
based on NR10, but implemented on all oscillators using timers
pace = 3 bits, direction, step [3 bits]
update period by 2^<step> every <pace> ticks of 128Hz timer (~8ms to ~55ms)
tics to complete: ~~~(period(N2) - period(N1)) / (1 << step) * pace (max=2048*)~~~ no, doesn't step by constant amount
PORT_STATE = { direction:, targetPeriod: }
- every 128Hz tick:
- if remaining:
    offset = period +/- (1 << step)
    if period within offset of target, set to target. else period += offset

MultiTimbral mode (poly off, default):
    each osc is assigned to a MIDI channel. each osc is monophonic, playing the most recent note received
Poly mode:
    each osc is assigned to a MIDI channel. within that channel, notes are polyphonic, switching between each assigned osc.
    if only one osc is assigned to the channel, it's effectively monophonic (mode 1)
